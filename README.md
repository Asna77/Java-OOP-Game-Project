# 🕹️ Java OOP Game Project – Asna F.

This is my upload for Java-OOP-Game-project.

The project is a **Java-based 2D game** built using the **Codename One framework**, implementing object-oriented principles, real-time movement, collision detection, and GUI updates using MVC architecture.

---

## 🎮 Features Implemented

✅ MVC Pattern (Model-View-Controller)  
✅ GameObject Hierarchy (Ant, Spider, FoodStation, Flag)  
✅ Real-time movement and collision detection  
✅ Observer Pattern for view updates  
✅ Key bindings and GUI commands  
✅ Sound toggle, About, Help, Exit dialogs  
✅ Wall bounce logic and life/health deduction

---

## 📁 Folder Structure

- `src/` – Source code files (.java)  
- `.codenameone/` – Codename One configuration  
- `Farooq-Asna-a3.zip` – Zipped version of the project (for easy download)  
- `README.md` – This file

---

## 🚀 How to Run the Project

1. Make sure [Codename One plugin](https://shannah.github.io/codenameone-manual/) is installed in your IDE (NetBeans, Eclipse (preferred), or IntelliJ).
2. Clone this repo or [download the ZIP](Farooq-Asna-a3.zip) and unzip it.
3. Open the project in your IDE.
4. Run the project using the Codename One simulator.
